# 高度順化チェック（AMSセルフチェック）

Wonders版AMS診断シートの4項目（頭痛・食欲/吐き気・めまい/ふらつき・睡眠障害、各0/1/3/7点）を朝夕に記録するオフライン対応Webアプリです。

- 公開URL: https://d8w9r55trf-maker.github.io/ams-check/
- 判定: 0〜4P 順調 / 5〜6P 停滞 / 7P以上 下山検討
- 記録は端末内（ブラウザ）に保存され、通信なしで使えます。
- ホーム画面に追加すると、圏外でも起動できます。

医学的診断の代わりにはなりません。

## バージョン管理のルール

1. 変更はすべてこのリポジトリで行う（Claude上の旧版は更新しない）
2. 変更は作業用ブランチで作り、プルリクエストで確認してから `main` に取り込む
3. 取り込むたびに `index.html` の `APP_VERSION`、`sw.js` の `CACHE`、`CHANGELOG.md` を同じ番号に揃える
4. 公開後、その版を `release/vX.Y.Z` ブランチとして残す
5. 記録の保存形式（`ams-records-v1`）を変えるときは、古い記録を自動変換する処理を必ず入れる
